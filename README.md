One warning label for a time machine, for the Funniest Time Machine
Warning Label on make.fun. The label was written by your future self —
which means the warning is not a guess, it is a report from someone who
already knows how this ends. And you ignored it then, too: the rider
has already ignored this exact label once before, in a previous loop,
and is doing it again right now. The setup and the payoff are the same
object (the label), so every word earns its place, and the paradox
lands in one read. Exactly what the brief asks for.

```sh
python3 main.py
```
